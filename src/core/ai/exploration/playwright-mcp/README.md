# Playwright MCP Exploration

This area is reserved for future AI-assisted live application exploration using
Playwright via MCP.

## Intent

Playwright MCP is intended to support:

- workflow discovery
- selector discovery
- assertion discovery
- evidence gathering for human review

## Important Rule

Playwright MCP is for discovery and review evidence only.

It must not replace the framework runtime layers:

- selectors
- components
- pages
- flows
- test execution

## Design Principle

Explore live, implement structured.
